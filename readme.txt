== Description ==

Enable your customers to pay for the submission of any data to your site with BuddyForms and WooCommerce and the Pay For Submissions Extension.

Charge for any kind of data submitted to your site. This can be a guest post or a link. A product like in an auction or any content or file format
like ( Images, Videos, Zip files, …) and much more!
